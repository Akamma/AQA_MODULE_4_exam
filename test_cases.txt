Фильмы

/GET MOVIES
1. Получение списка всех фильмов
2. Получение списка фильмов с различными параметрами фильтрации (проверит
проверить каждый параметр, что вывод ограничивается)
3. Проверить ошибки при получении списка фильмов с не корректными данными
/POST MOVIES
1. Создание фильма - c кредами супер админа
2. Создание фильма - без необходимых полномочий
3. Проверить статус код при создании фильма с не корректными параметрами
4. Проверить статус код при создании уже существующего фильма
/GET MOVIES {ID}
1.Поиск существующего фильма
2.Поиск не существующего фильма
/DELETE MOVIES {ID}
1.Удаление существующего фильма с кредами супер админа
2.Удаление фильма без полномочий супер админа
3.Удаление не существующего фильма
/PATCH MOVIES {ID}
1.Обновление с кредами супер админа
2.Обновление без полномочий
3.Обновление без каких либо данных
4.Обновление не существующего фильма

Отзывы
/GET MOVIES/{ID}/REVIEW
1.Получение отзыва о фильме
2.Получение отзыва о не существующем фильме
3.Получение пустого отзыва

/POST MOVIES/{ID}/REVIEW
1.Создание отзыва
2.Создание нескольких отзывов
3.Создание отзыва к несуществующему фильму
4.Создание отзыва без аутентифакации
5.Создание несколько отзывав к фильму
6.Создание отзыва к удаленному фильму

/PUT MOVIES/{ID}/REVIEW
1.Редактирование своего отзыва
2.Редактирование не своего отзыва
3.Редактирование без аутентификации
4.Редактирование не существующего отзыва

/DELETE MOVIES/{ID}/REVIEW
1.Удаление своего отзыва под ADMIN
2.Удаление своего отзыва под USER
3.Удаление не своего отзыва под ADMIN
4.Удаление не своего отзыва под USER
5.Удаление не существующего отзыва
6.Удаление отзыва к удаленному филму

/PATCH MOVIES/{ID}/REVIEW/hide/{ID}
1.Скрытие отзыва с ролью ADMIN
2.Скрытие отзыва с роль USER
3.Скрытие не существующего отзыва

/PATCH MOVIES/{ID}/REVIEW/show/{ID}
1.Показ отзыва с ролью ADMIN
2.Показ отзыва с ролью USER
3.Показ скрытого отзыва
4.Показ открытого отзыва

Жанры
/GET GENRES
1.Получение жанров

/POST GENRES
1.Создание не существующего жанра
2.Создание существующего жанра
3.Создание жанра с не валидными параметрами

/DELETE GENRES{ID}
1.Удаление существующего жанра
2.Удаление не существующего жанра
3.Удаление жанра с ролью USER

/GET GENRES{ID}
1.Получение существующего жанра
2.Получение не существующего жанра
